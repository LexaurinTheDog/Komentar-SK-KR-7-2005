# Komentár k zákonu č. 7/2005 Z. z., o konkurze a reštrukturalizácii

Odborný komentár k slovenskému zákonu o konkurze a reštrukturalizácii — **305 paragrafových jednotiek** (§ 1 – § 208 vrátane písmenných vsuviek) s doslovným znením a vecným výkladom.

Konsolidované znenie k **1. 10. 2025**, zdroj [slov-lex.sk](https://www.slov-lex.sk/static/SK/ZZ/2005/7/20251001.html).
